# Plan: 数独游戏 (Sudoku)

**Complexity**: Large
**Target**: 1280×800 landscape, lvgljs API only

## Summary
纯 JS 数独游戏应用，自包含单包部署。棋盘用 9×9 格子渲染，3×3 宫分区着色，点击格子弹出半透明 3×3 数字选择器。支持三级难度、保存/加载、撤销、提示、完成检测。

## 视觉设计

- 3×3 宫交替深浅色底色
- 选中格蓝色高亮，同行列淡蓝条带
- 原始提示数字粗黑，玩家填入蓝色
- 冲突数字红色闪烁
- 主题色可配置（theme.json）

## API 新增

| 函数 | 说明 |
|------|------|
| `lvgljs.readFile(path)` → string | 读取文件 |
| `lvgljs.writeFile(path, data)` → bool | 写入文件 |

## 实施步骤

1. 添加文件 I/O API（js_bridge.cpp）
2. 数独核心算法（生成/验证/求解）
3. UI 渲染（棋盘 + 弹窗 + 控制栏）
4. 交互逻辑（选格/填数/冲突检测/完成检测）
5. 持久化（保存/加载）
6. 打包部署测试
